# ECSE321 Online Shop Project: Team 18

## Project Overview
This project is a online store for a clothing shop that allows customers to browse and order clothing items. The system supports multiple user roles, including customers, employees, and a manager, each with role-specific access. Customers can browse the product catalog, manage their shopping cart, and place orders by providing an address and delivery date. Employees prepare customer orders, while the manager oversees the delivery preperations and maintains the product catalog.

This is a group project associated with ECSE 321 - Intro. to Software Engineering, at McGill University.
